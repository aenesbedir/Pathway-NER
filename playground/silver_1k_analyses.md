## Headline — did we break the near-lookup problem?

The whole motivation: exact matching produced only 105 case-folded surface forms across 73k spans corpus-wide, so a model trained on it learns a lookup table. Both sides below are counted on the **same 1,000 abstracts, abstract-only**.

| | Exact matching | Silver (LLM + booster) |
|---|---|---|
| Spans | 1,343 | 1,996 |
| **Unique surface forms** | **81** | **532** (6.6×) |
| Abstracts with ≥1 span | 840 | 915 |
| Distinct Recon pathways named | 60 | 64 |

- **457 surface forms are new** — never produced by exact matching on these abstracts (86% of the silver vocabulary).
- 75 surfaces overlap with exact matching.
- 6 exact-matching surfaces are **absent** from silver (recall gaps — the LLM did not return them).

## Vocabulary coverage (NOT a quality metric)

How many surfaces we could put a Recon name to. **`unmapped` does not mean 'not a pathway'** — it means we could not name it. `kynurenine pathway` is a real pathway with no Recon subsystem; it is unmapped and still a valid positive for a binary tagger (labels are `O`/`B-Pathway`/`I-Pathway`; the canonical never enters the label).

| match_type | spans | share |
|---|---|---|
| `exact` | 1,012 | 51% |
| `synonym` | 174 | 9% |
| `variation` | 238 | 12% |
| `unmapped` | 572 | 29% |

- **Mapped to a Recon name: 1,424 (71%)** · unmapped: 572 (29%)
- **The payoff: `variation` + `synonym` = 412 spans (21%)** — mentions exact matching would miss entirely, *plus* an unknown share of the unmapped bucket.
- Unique unmapped surfaces: 353

## What this does not tell us

- **Precision** — needs the doccano review. Golden measured 0.95 on 5 abstracts; whether that holds here is unknown.
- **Recall** — we cannot count mentions the LLM never proposed. Golden put `span:variation` recall at 5/6 (83%); the `missed_surfaces` count above is a partial proxy on exact-matchable forms only.
- **Whether unmapped spans are real pathways** — by construction we could not name them; only a human can say.
